# 苏丹的游戏本地剧情阅读器

这是一个面向《苏丹的游戏》的本地剧情阅读器，重点服务仪式、幕后、后续分支与相关图片的阅读，不追求完整复刻原游戏数值与系统玩法。

## 主要功能

- 以本地阅读器方式查看仪式、幕后、后续分支和相关文本
- 提供节点图与正文阅读两种互补浏览方式
- 支持加载并展示本地提取出的图片资源
- 支持捐赠图片显示
- 支持从用户自己的游戏目录读取 `config`、`cache`、`resource` 相关内容

## 如何使用

1. 运行程序后，在启动页选择游戏安装目录。
2. 按需配置 `AssetStudio.CLI.exe`、资源目录和缓存目录。
3. 如还没有资源与缓存，可先提取游戏资源，再更新配置缓存。
4. 点击“进入主界面”开始阅读仪式、幕后与分支内容。

## 打包版说明

- Windows 目录版程序位于 `sultan-reader/release/win-unpacked/SultanReader.exe`
- 当前默认提供目录版，而不是单文件便携版，以减少被安全软件误报的概率
- 打包产物不包含仓库根目录下的 `config/`、`cache/`、`resource/` 或游戏原始资源文件，程序会在运行时读取用户自己本地游戏目录中的内容

## 依赖说明

- 正常打开阅读器本身不需要额外安装 `.NET`
- 只有在使用“提取游戏资源”功能时，才需要 `.NET 8` 运行时和 `AssetStudio.CLI.exe`
