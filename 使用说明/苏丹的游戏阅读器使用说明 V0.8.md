# 下载安装及初始化
## 下载

下载地址： https://pan.quark.cn/s/6a104a7f525d

![[Pasted image 20260413190427.png]]

下载苏丹的游戏阅读器 解压后，打开 SultanReader.exe 使用即可，初次打开游戏和加载资源时可能较慢，请耐心等待

![[Pasted image 20260413190513.png]]
## 初始化

打开时会默认寻找 Steam 游戏安装目录，如果没有找到，需要手动点击浏览找到游戏安装路径

![[Pasted image 20260413190611.png]]

找到游戏目录后，点击**更新配置缓存**按钮，和**提取游戏资源**按钮来读取游戏配置和图片资源，注意，提取游戏资源需要电脑中已经安装了 .NET 8，才能通过 AssetStudio CLI 提取图片资源，如果没有安装可以从网盘中下载安装 dotnet 安装包，或者从官网  [https://dotnet.microsoft.com/download](https://dotnet.microsoft.com/download) 下载

![[Pasted image 20260413190942.png]]

提取的过程可能较慢，请耐心等待

![[Pasted image 20260413192341.png]]

![[Pasted image 20260413192206.png]]
## 使用缓存初始化

或者，如果你之前已经把游戏删除了，也可以下载夸克中我本地已经打包好的一份**游戏资源缓存包**来获取资源： 

![[Pasted image 20260413191448.png]]

解压完成后，将目录配置的资源（resource）和缓存（cache）分别设置为解压后目录下的 resource 和 cache 即可

或者，你也可以在将 resource 和 cache 目录复制到阅读器的根目录下，初始化时会自动复制这两个目录到缓存目录下（不建议，可能导致第一次初始化时比较慢）

![[Pasted image 20260413192908.png]]

![[Pasted image 20260413192832.png]]
## 读取 Mod 资源

如果你不需要读取 Mod 剧情，可以跳过

![[Pasted image 20260413191658.png]]

Mod 通常通过创意工坊下载在 Steam\steamapps\workshop\content\3117820 路径下，阅读器会根据游戏路径尝试自行寻找 Mod 安装路径，如果没找到也可以点击浏览按钮自行修改目录
勾选想要加载的Mod，然后点击读取按钮，阅读器会将Mod的内容也加载到缓存中，从而可以读取Mod的相关内容

![[Pasted image 20260413191904.png]]

## 开始使用

![[Pasted image 20260413192643.png]]
全部设置完毕后，就点击**进入主界面**开始使用吧！
# 使用

## 布局

左侧为游戏的内容区域，按照类型划分为仪式、幕后、战利品，结局；这四项可以作为节点在画布上展示

后日谈、卡牌、对话树则仅有详情可以查看

![[Pasted image 20260413192422.png]]

右上角有导出导入节点图按钮作为存档功能，清空可以初始化画布，设置按钮可以跳转到之前的游戏设置界面，后续打开默认是直接进入主页面而非设置页面

中间是画布区域，点击节点即可查看其对应详情，右下角为节点图缩放预览图

## 节点

所有节点悬停时可以看到左右的按钮，+ 号按钮点击时可以带出该节点关联的其他节点， x 按钮会删除该节点和子节点

![[Pasted image 20260413193243.png]]

### 仪式准备

点击仪式节点可以进入查看详情，左上角会显示该仪式可以使用的卡槽，点击卡槽会切换卡槽的相关说明，并在左下方预览该卡槽**可能**可选的卡牌

右侧是仪式的执行前文本展示区域，会展示该仪式的正文和一些选择当前卡槽时的对白，但是仪式卡牌的选择实际不会影响结算界面的流程，结算流程中仍然可以自由选择查看分支，因此不用特别注意选牌，点击进入结算查看即可

![[Pasted image 20260413193606.png]]

左下角的条件块可以点击，也可以直接点击 <> 箭头切换卡槽条件

![[Pasted image 20260413193807.png]]

点击后可以选择不同的满足条件的卡牌

![[Pasted image 20260413193844.png]]

右上角的按钮可以查看背景图、收藏、设置已读等

### 仪式结算

点击进入结算按钮后可以查看仪式进行中的文本，可以随时滚动查看文本和条件

![[Pasted image 20260413194006.png]]

点击一个条件块，可以查看该组条件的内容

![[Pasted image 20260413194113.png]]

点击后可以查看该条件下的分支结果

![[Pasted image 20260413194204.png]]

仪式会结束后中止显示后续的条件，因此如果要看后面的结算，建议将前面会导致中止的条件设置为跳过，仪式获取的卡牌及资源、计数器、开启的仪式会在左边呈现，需要注意的是开启的仪式是只要在条件中出现过一次，后续即使切换条件也不会消失，这是特意设置来显示分支用的，节点图中也可以看到仪式关联的节点，并不是 bug

![[Pasted image 20260413194236.png]]

### 幕后

点击一个幕后可以查看该幕后的详情，点击选项可以看到相关的后续文本，带出其关联的事件，大部分幕后可能仅为仪式的触发器，没有文本

![[Pasted image 20260413194605.png]]

### 战利品

战利品节点可能可以查看关联的幕后、卡牌等，点击后可以查看其详情

![[Pasted image 20260413194719.png]]

### 结局

结局节点会展示其背景图和文本

![[Pasted image 20260413194812.png]]

如果是好结局，还可以滚动查看该结局下可能存在的角色后日谈

![[Pasted image 20260413194850.png]]

点击角色，可以查看其该结局下后日谈的详情文本，包括条件分支，点击上下条可以切换展示不同分支下的后日谈，文本的颜色代表的是同一结局下出现该文本的频率；点击上下结局可以切换不同角色的该结局后日谈

![[Pasted image 20260413194930.png]]

## 后日谈

后日谈没有节点，可以通过点击内容详情的分支阅读或不同结局来查看其后日谈内容

![[Pasted image 20260413195151.png]]

详情与结局中的后日谈类似，但是点击切换结局是切换该角色在不同结局下的后日谈

![[Pasted image 20260413195312.png]]

显示卡牌详情

![[Pasted image 20260413195406.png]]
